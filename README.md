# Hi, I'm Cesia 👋

I'm a curious, interdisciplinary lifelong learner. Most of what I build involves AI agents, where the interesting question is not what a single model call returns but how you split a task among several, what each one sees, and what carries forward between turns. I've built memory architectures that decide what an agent should forget, retrieval pipelines that keep an answer tied to its source, and engines that turn a rubric written in prose into criteria a machine can check.

I think a lot about learning itself: what good pedagogy looks like in a classroom, and what it looks like when the learner is a model. I like the research side as much as the engineering. I want to know why something works, so I read the literature, reproduce the result myself, then run the experiment that could tell me I'm wrong.

Outside of that I love a good number theory problem, and enjoy good storytelling in a film or a song. I love Christian apologetics and philosophy.

### 🛠️ What I'm building

**Discussion Prep** · Socratic discussion coach for MIT courses 11.268 and 11.200
Students practice building arguments from assigned readings and get counterarguments grounded in the texts. Hybrid retrieval (BM25 via SQLite FTS5 + dense vectors via sqlite-vec, fused with weighted RRF), Docling ingestion, and a knowledge graph showing how readings depend on each other.

**Building Bridges** · Practice space for hard parent-teacher conversations
Teachers rehearse conferences across 11 classroom scenarios (absenteeism, bullying, accommodations, grading, and more), with documentation like attendance records and referrals surfacing mid-conversation, the way it does in real life.

**Multiple Representations** · Teacher skill practice
Teachers see real student work, diagnose the misconception, and respond with tabular, algebraic, geometric, and real-world representations.

**Course Fingerprints** · Course discovery for MIT undergrads
AI-seeded "fingerprints" (the questions you should be able to answer after a course) that students then edit wiki-style, searched with hybrid RAG.

### 🔬 Research and experiments

- **Perturbation benchmark for mathematical reasoning:** structure-preserving variants of AIME-style problems to test whether models reason or recall

- **Movement to structure:** spectral analysis of non-normal Markov operators on movement data (pigeon GPS, desire paths)
